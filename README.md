   fires on Bahrain and Kuwait; oil near $93.
2. **Xi & Putin meet** — in Shenzhen, a day before a first-ever summit with

3. **Kerch Bridge hit** — Ukraine strikes again; part of the road span

4. **Cyclone Akvan** — strengthening in the Bay of Bengal; landfall due
   Friday; winds 100–110 kmph, evacuations begin.
5. **Democrats take the Senate** — Peltola wins Alaska; majority now 56–44;
   Smith takes a North Carolina House seat.
6. **Nvidia's $115.8B quarter** — revenue doubles; board rejects Huang's

## How it is built

`entry.png` (1024×1024, PNG) is a clean newspaper-style infographic drawn
with crisp vector text, so every headline stays legible when the image is
shrunk. `main.py` (Python 3.13, standard library only) copies it byte for
byte to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`).

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
